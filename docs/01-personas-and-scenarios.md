## 첫번째 페르소나:신태일 (완전 초보)

- 지방에서 자취 중, 집에 누군가 있었으면 하는 외로움이 있음
- 반려동물 경험 전무 (구피 한 마리도 키워본 적 없음)
- 도마뱀을 여러 마리 키우는 친구(B)가 있음
- "생각보다 키우기 빡세지 않은데 엄청 귀엽다" → 키우고 싶어짐

### 사용자 진입 경로

**1A. 준비형: 입양 전 진입**

- 분양받기 전, 무엇을 준비해야 하는지 고민
- 필요: 준비물 체크리스트, 초기 비용 안내, 분양 시 샵에 물어볼 질문 리스트
- 분양 시 받아온 정보가 "내 녀석"의 첫 기록이 됨

**1B. 충동형: 입양 후 진입**

- 덜컥 분양받아버림, 준비가 덜 됐을 가능성 높음
- 모를 때마다 친구에게 묻거나 가게에 갈 수 없음 → 인터넷/외부 LLM 의존
- 문제: 정보가 흩어져 있고(허브 없음), 전부 일반론이라 **내 개체에 맞는 답**을 못 얻음
- 필요: 첫 화면에서 "지금 당장 위험한 것" 긴급 점검 → 이후 입문 코스로 합류

### 여정 단계

| 단계           | 상황                      | 앱의 역할                                                 |
| -------------- | ------------------------- | --------------------------------------------------------- |
| 0. 입양 전     | "나도 키울 수 있을까?"    | 준비 가이드 (1A)                                          |
| 1. 입양 직후   | "이게 정상이야?"          | 긴급 점검(1B) + 입문 코스                                 |
| 2. 적응기      | "우리 애"가 되는 시기     | 이름·사진·추억 기록 (정서적 가치, 검토 중)                |
| 3. 익숙해진 후 | 가끔 확인                 | 최소한의 기준선 유지                                      |
| 4. 이상 상황   | 밤 11시, 물어볼 사람 없음 | 기록 기반 판단 보조 + 병원 권고 + 근처 특수동물 병원 정보 |

## 페르소나 B: 숙련자 친구

- 2~3년 차, 여러 마리·여러 종 사육
- 기본 사육은 이미 익숙함, 초보 친구들의 질문에 답해주는 위치

### 역할 1 — 평가자

- "이 앱이 말하는 수준이 괜찮나?"를 판단
- 틀린 정보를 한 번만 자신 있게 말해도 → "쓰지 마"
- 인정받으면 → 초보 친구들에게 추천하는 핵심 유입 경로

### 역할 2 — 실사용자 (유료 기능 후보)

- 입문 코스·기본 Q&A는 필요 없음
- 원하는 것: **집에 없을 때의 안심** (겨울 히터 고장, 여름 폭염·정전)
- Wi-Fi 온습도계 연동 + 위험 시 알림 → 유료 기능 후보
- BLE는 휴대폰이 근처에 있어야 해서 이 요구를 못 채움
- 센서 하드웨어 직접 제작 X → 시판 Wi-Fi 온습도계 중 API 제공 제품 연동 검토 (V2)

## 시나리오에서 도출된 요구사항

| 구분      | 요구사항                                                        | 출처 |
| --------- | --------------------------------------------------------------- | ---- |
| 입양 전   | 준비물 체크리스트, 초기 비용 안내, 분양 시 질문 리스트          | A-1A |
| 온보딩    | 사육 경험 수준 질문 → 초보는 입문 코스, 숙련자는 바로 관리 화면 | A, B |
| 입양 직후 | 긴급 환경 점검, 개체 등록, 입문 코스                            | A-1B |
| 박사      | 내 개체 맥락 기반 Q&A, 한곳에 모인 신뢰할 만한 가이드           | A    |
| 박사 품질 | 정확도 우선, 불확실하면 인정, 답변 근거 표시                    | B    |
| 적응기    | 이름·사진·추억 기록 (검토 중)                                   | A    |
| 이상 상황 | 기록 기반 판단 보조, 병원 권고, 근처 특수동물 병원 정보         | A    |
| 데이터    | UI는 V2여도 DB는 처음부터 여러 마리 구조                        | B    |
| 수익      | 무료: 입문 + 박사 / 유료: Wi-Fi 센서 연동 원격 알림             | B    |
