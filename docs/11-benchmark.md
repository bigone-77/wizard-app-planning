# 11. 벤치마킹

> 상태: 2차 완료 (2026-10-12) — 홈 화면 구조 비교 추가
> 목적: 기존 파충류 케어 앱의 홈 구성·기능·사용자 불만을 파악하고, 지금까지의 기획(01~10)과 비교
> 다음 단계: 우리 홈 스켈레톤 보완

---

## 조사 방법과 한계

- 앱 설명, 업데이트 내역, 사용자 리뷰, **공식 홈페이지·스토어에 공개된 앱 화면 이미지**를 기준으로 조사
- 렙다이어리는 사용 후기 블로그의 앱 화면으로 확인 (홈 탭 화면은 자료에 없음)
- 홈 구조는 원본 화면을 옮기지 않고 **회색 박스 스켈레톤**으로 다시 그림 (구조 분석용)
- 평점·평가 수는 조사 시점 기준

---

> 정정: 1차 조사에서 분석한 "ReptiCare"는 Google Play의 같은 이름의 다른 앱(4.4점, 10마리 무료)이었음. 벤치마킹 대상은 스위스 ReptiCare로 확정.

**발견**

- **압도적인 1위가 없음.** 평가 수가 가장 많은 앱도 백여 개 수준 → 작은 시장이 잘게 나뉜 상태
- 시장이 작다는 우려를 데이터로 확인. 동시에 **확실한 강자가 없어 진입 여지가 있음**
- **한국어 AI 상담 앱은 조사 범위에서 찾지 못함**

## 홈 화면 구조 비교

같은 형식의 스켈레톤으로 나란히 비교. 디자인이 아닌 **"어디에 무엇이 있는지"**만 표현.

### TerraGuard

![TerraGuard 홈 스켈레톤](/benchmark/terraguard-home.svg)

| 항목                | 내용                                                                                                                                                                                            |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈 구성             | 인사 + 오늘 남은 할 일 수 → 기한 지남 배지(빨강) → 사육장 카드(온도·습도·UVB 사용일) → 개체 카드(나이·마지막 급여·체중) → 오늘 할 일 진행률 → 기한 지난 할 일 → 오늘 할 일                      |
| 첫눈에 보이는 것    | **해야 할 일과 밀린 일**                                                                                                                                                                        |
| 특징                | 사진 AI 4단계 판정(정상/관찰/주의/병원), 개체별 AI 채팅("Rex에게 물어보기"), 채팅 입력창 위에 **추천 질문 칩**("이 똥 정상이야?", "칼슘 얼마나?"), 30일 진료 PDF, 영양제 순환 스케줄, 익명 계정 |
| 우리와 비교         | 같음: 단계별 위험 판정, 개체 맥락 상담, 하단 칩 방식(09), 진료 요약 / 다름: 할 일 중심 홈, 영어, 캐릭터 없음                                                                                    |
| 가져올 것 · 피할 것 | 가져올 것: 채팅 추천 질문 칩, 개체 이름이 들어간 입력창 문구 / 피할 것: 빨간 "기한 지남" 배지와 할 일 개수 압박                                                                                 |

### Exotic Reptile Care

![Exotic Reptile Care 홈 스켈레톤](/benchmark/exotic-reptile-care-home.svg)

| 항목                | 내용                                                                                                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈 구성             | "내 파충류" → 개체 사진 카드 2열 그리드(이름·종·**마지막 급여 N시간 전**) → 추가 버튼                                                                                        |
| 첫눈에 보이는 것    | **내 동물들과 마지막 급여 시점**                                                                                                                                             |
| 특징                | 먹이 재고 자동 차감, 탈피 주기 예측, 투약 기록, 영양제(브랜드·더스팅·섭취 여부) 별도 기록, 번식 프로젝트, 20종+ 케어 가이드. 계정 없음, 기기 저장, 오프라인 동작. 5마리 무료 |
| 우리와 비교         | 같음: 먹이 거부, 영양제, 진단하지 않는다는 태도 / 다름: 기록 입력이 긴 폼(먹이 종류·크기·수량·재고·날짜·시간), AI 상담 없음                                                  |
| 가져올 것 · 피할 것 | 가져올 것: 개체 카드의 "마지막 급여 N시간 전" 한 줄 / 피할 것: 항목이 많은 기록 폼 (우리는 음성 + 확인 카드)                                                                 |

### ReptiCare (스위스)

![ReptiCare 홈 스켈레톤](/benchmark/repticare-home.svg)

| 항목                | 내용                                                                                                                                                                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈 구성             | "내 동물" + 검색 → 인사("N마리를 돌보는 중") → 요약 타일 4개(동물 수·오늘 일정·오늘 급여·기한 지남) → **다음 할 일** 카드 → 종 카테고리                                                                                                            |
| 첫눈에 보이는 것    | **오늘 현황 숫자와 다음 할 일**                                                                                                                                                                                                                    |
| 특징                | 체중 그래프에 **목표 범위** 표시("현재 목표 범위 안"), "체중 감소"·"반복 급여 거부" 경고 규칙, **겨울잠 중·직후에는 급여 공백 경고를 끔**, 스위스 동물복지법 기준 사육장 크기 검사(신호등), 계정 없음(iCloud 동기화), 2마리 무료 · Pro 일회성 결제 |
| 우리와 비교         | 같음: 기록 기반 경고 규칙(04 기록 시점 검사), 진단 대체 아님을 명시 / 다름: 법규 중심, AI 없음                                                                                                                                                     |
| 가져올 것 · 피할 것 | 가져올 것: "다음 할 일" 카드, 체중 목표 범위 표시, **계절에 따른 경고 규칙 조정** / 피할 것: 숫자 타일 위주의 대시보드(초보에게 정보가 많음)                                                                                                       |

### Gecko Expert

![Gecko Expert 홈 스켈레톤](/benchmark/gecko-expert-home.svg)

| 항목                | 내용                                                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈 구성             | 인사 + 응원 문구 → 주간 날짜 → 도구(AI 건강 진단·시세 확인) → **"AI 전문가에게 묻기"** 큰 버튼 → 오늘의 계획 체크리스트(온도 체크, 외관 체크)        |
| 첫눈에 보이는 것    | **AI 기능으로 들어가는 버튼**                                                                                                                        |
| 특징                | 사진 스캔 결과에 "의심 소견 + 위험도" 표시 후 **"치료 조언 받기"** 버튼, 24시간 채팅, 시세 추정. 같은 개발자가 종별로 앱을 복제 출시. 주간·연간 구독 |
| 우리와 비교         | 같음: 게코 한 종 집중, AI 상담 / 다름: 홈에 **내 개체 정보가 없음**(일반 도구 모음), 치료 조언을 내세움                                              |
| 가져올 것 · 피할 것 | 가져올 것: 짧은 "오늘의 계획" / 피할 것: 개체 없는 일반형 홈, 진단·치료처럼 보이는 표현 (우리 원칙: 진단하지 않는다)                                 |

![렙다이어리 다이어리 탭 스켈레톤](/benchmark/repdiary-diary.svg)

| 항목                | 내용                                                                                                                                                                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 화면 구성           | (다이어리 탭) 개체 사진·이름·종 → 기록 카테고리 아이콘(온욕·청소·병원·기타·필터) → **월간 캘린더에 날짜별 기록 아이콘** → 선택한 날짜                                                                                                 |

| 우리와 비교         | 같음: 개체별 기록, 성별 "미구분" 허용(02) / 다름: 커뮤니티·분양 중심, AI 없음                                                                                                                                                         |
| 가져올 것 · 피할 것 | 가져올 것: 캘린더로 보는 기록 패턴(기록 목록의 보기 방식 후보), 샵 정보와 "단골"(가게 제휴 Later 참고) / 피할 것: V0에서 커뮤니티·분양까지 넓히기                                                                                     |

![우리 홈 - 적응 미션 중](/benchmark/ours-home-adaptation.svg) ![우리 홈 - 익숙해진 후](/benchmark/ours-home-settled.svg)

## 홈 비교에서 나온 시사점

| 발견                                          | 앱                                  | 우리 홈에 반영                                                                        |
| --------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------- |
| "다음 할 일"이 거의 모든 홈에 있음            | TerraGuard, ReptiCare, Gecko Expert | 익숙해진 후 홈에 박사의 약속·미션 기반 **"다음 체크" 한 줄** 추가 검토                |
| 개체 카드에 마지막 급여 시점                  | Exotic Reptile Care                 | 개체 요약에 **"마지막 급여 N일 전"** 포함 검토                                        |
| 빨간 기한 지남 배지, 할 일 개수               | TerraGuard                          | 넣지 않음 ("매일 강요하지 않는다")                                                    |
| 개체 정보 없는 일반 도구형 홈                 | Gecko Expert                        | 넣지 않음 (우리는 "내 도마뱀을 기억하는" 박사)                                        |
| 채팅 입력창 위 추천 질문 칩, 개체 이름 입력창 | TerraGuard                          | 09 하단 칩 방식이 맞음을 확인. 박사 대화 첫 화면에 추천 질문 칩 검토                  |
| 캘린더로 보는 기록 패턴                       | 렙다이어리                          | 기록 탭의 보기 방식 후보 (목록 / 캘린더)                                              |
| 겨울잠 중 급여 공백 경고 끄기                 | ReptiCare                           | **기록 시점 검사 규칙에 계절 고려** 검토 (겨울철 식욕 감소 가능성, 자료 검토 후 확정) |

## 분석

### 업계 표준 — 해야 하는 기본기

먹이 거부, 진료용 요약, 리마인더, 영양제 기록은 대부분 보유.

- 진료용 요약은 방향이 맞음. **PDF 내보내기**는 우선순위 결정 필요

### 우리만의 차별점

다섯 앱 중 아무도 하지 않는 것: 입양 전부터의 여정, 적응기 미션, 캐릭터 박사와의 대화, 참고 자료 표시, 음성 기록, **한국어 + AI 상담**, **사용 단계에 따라 바뀌는 홈**

### 위협 — TerraGuard

- 자연어 기록, 개체별 AI 채팅, 추천 질문 칩까지 이미 보유. 개발 속도가 빠름
- → 차별점은 **따라 하기 어려운 것**에 둔다: 한국어, 캐릭터 박사, 한 종에 대한 깊이, 입양 전부터의 여정

### 계정 없이 쓰기

다섯 앱 중 세 개가 **계정 없이 시작**을 장점으로 내세움 (익명, 기기 저장, iCloud).

- 우리는 서버 푸시·데이터 보존 구조상 개체 등록 시 가입 필요 → 유지
- 대신 **가입 전에 박사를 충분히 경험**하게 하는 현재 흐름(08)이 중요함
