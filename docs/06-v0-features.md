## V0의 성격

**V0는 정식 출시가 아니라 알파 테스트**다. 소수의 테스터가 핵심 경험(박사, 기록, 미션)을 검증하고 피드백을 남기는 단계. 이 문서는 **V0에서 만들 것**에 집중한다.

| 항목                               | V0 (알파)                                                     |
| ---------------------------------- | ------------------------------------------------------------- |
| 앱 사용                            | **로그인해야 사용 가능** (비회원 사용 없음)                   |
| 개체                               | **회원당 1마리 고정**                                         |
| 박사 사용량                        | 하루 예산 (글 대화 1 · 사진 분석 3). 알파 테스터에겐 넉넉하게 |
| 위험 신호 확인·병원 권고·기록 요약 | **한도와 무관하게 항상 가능** (LLM 미사용)                    |

> 확장 대비: DB는 여러 마리 구조, 개체 수·박사 예산은 서버 설정값 → V1에서 코드 변경 없이 조정 가능

## 병원 권고 방식 (01의 V0 결정 변경)

### 변경 이유

- 지도 API로 "파충류 진료 가능 병원"을 필터링하면 정보가 불확실하거나 거의 없음
- 앱 안에 병원 목록을 띄우면 그 정확성에 대한 책임이 앱으로 넘어옴
- 감당하려면 자체 검증 목록 관리 필요 → V0 규모를 넘음 (배보다 배꼽)

### 바뀐 방향: 병원을 찾아주는 대신, 병원에 가는 걸 돕는다

**1. 진료용 기록 요약**
박사가 병원을 권고할 때 그동안의 기록을 수의사에게 보여줄 한 장으로 정리. 화면으로 보고 **PDF로 내보내 공유**.

> 원칙: **박사는 병명을 말하지 않는다. 대신 수의사가 진단하는 데 필요한 정보를 모으고 정리한다.** (12)

담는 정보:

- 증상 시작 시점과 반복 횟수
- 먹이·배변·체중·탈피 기록
- 사육 환경 (V0는 박사 질문에서 받은 관찰 기록. 정확한 온도는 사육장 정보가 생긴 뒤)
- 최근에 바뀐 것 (새 먹이, 탈피 등)
- 관련 사진
- (Should) 수의사에게 물어볼 질문

```text
콩이 · 펫테일 게코 · 아성체 · 분양 2026-10-02

- 분양 4일째부터 급여 거부 (시도 3회 / 섭취 0회)
- 최근 배변 3회 중 2회 묽음
- 체중 기록 없음
- 사육 온도: 바닥 "따뜻함" (수치 미확인)
- 외관: 사용자 응답 기준 이상 없음
```

- 초보는 병원에서 경과와 사육 환경을 설명하기 어려움
- 이미 쌓인 기록을 쓰므로 추가 데이터 관리 없음
- **이 앱만 할 수 있는 일**

**2. 외부 지도 검색 바로가기**

- 버튼을 누르면 카카오맵/네이버 지도 앱이 "특수동물병원" 검색어로 열림 (앱 미설치 시 웹 지도 검색)
- 앱은 필터링·검증을 하지 않고 지름길만 제공 → 관리 부담 없음
- 박사: "가기 전에 꼭 전화로 파충류 진료 되는지 확인해!"
