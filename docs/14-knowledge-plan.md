# 14. 지식 계획

> 상태: 확정 (2026-10-18) — V0(알파) 기준
> 용도: 박사가 참고하는 펫테일 핵심 지식을 어디서, 어떻게 모으고 정리할지
> 근거 문서: 05, 10, 12, 13

---

## 전제

**펫테일 사육에는 모두가 합의한 "공식 문서"가 없다.** 같은 주제를 두고 자료마다 말이 다르다.
예: UVB 필요 여부, 사육장 최소 크기, 바닥재.

그래서 하나의 공식 문서를 찾는 대신

1. **믿을 수 있는 순서를 정해두고**
2. **자료끼리 다르면 다르다고 표시한다** (`is_contested`, 10)

---

## 자료 신뢰 순서

| 순위 | 자료                                                       | 쓰는 곳                              |
| ---- | ---------------------------------------------------------- | ------------------------------------ |
| 1    | 수의학 자료 (파충류 수의학 교과서, 학술 논문, 수의 매뉴얼) | 질병 징후, 위험 신호, 병원 권고 기준 |
| 2    | 수의사가 만든 케어시트 (동물병원 배포 자료)                | 기본 사육, 건강 관리                 |
| 3    | 근거를 밝히는 전문 케어 가이드                             | 사육 환경, 급여, 영양제              |
| 4    | 숙련 사육자 검토                                           | 1~3의 실전 감각 보완                 |
| 제외 | 커뮤니티 글, 출처 없는 블로그                              | 질문 수집용으로만 (정답지 질문 후보) |

- 먹이·용품을 판매하는 사이트의 케어시트는 같은 순위 안에서 낮게 본다 (중립성)

### 우선순위

1. **즉시 병원 신호 목록** — 위험 신호 규칙(04)과 사전 설계 흐름의 근거
2. 정답지에 쓰인 주제 (굵게)
3. 나머지

### 확정이 필요한 수치 (13에서 나옴)

나이별 더스팅 빈도, 계절에 따른 식욕 변화 정도, 바닥 온도 범위, 사육장 최소 크기, 급여 거부 경고 기준(04), 체중 감소 경고 기준(04)

## 작성 규칙

| 규칙                   | 내용                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| **우리 말로 요약**     | 원문을 복사하지 않는다. 사실만 우리 문장으로 쓰고 출처는 링크로 (원문은 각 사이트의 저작물)     |
| **수치는 범위와 출처** | "바닥 ○~○℃ (출처 A)". 자료마다 다르면 양쪽 모두                                                 |
| **의견 갈림 표시**     | 자료끼리 다르면 `is_contested = true`, 내용에 양쪽 입장을 함께                                  |
| **근연종 표시**        | 펫테일 자료가 부족해 레오파드 게코 등 근연종 자료를 쓰면 내용 첫 줄에 `[근연종: 레오파드 게코]` |
| **병명 다루기**        | 지식에는 병명을 포함해도 된다. 답변에서 쓰지 않는 건 박사 원칙(12)이 정함                       |
| **제품명 없음**        | 종류와 조건만 ("흙과 모래를 섞은 바닥재")                                                       |
| **검토일**             | 작성·검토한 날짜 기록 (`reviewed_at`)                                                           |
| **삭제 대신 비활성화** | 틀린 자료는 `is_active = false` → 과거 답변의 참고 자료는 유지 (10)                             |

### 조각 형식 예시

```text
id:            ftg-021
species:       fat_tailed_gecko
topic:         shedding
title:         탈피 후 발가락에 껍질이 남았을 때
is_contested:  false
source:        ReptiFiles 레오파드 게코 탈피 (근연종)
reviewed_at:   2026-10-18

[근연종: 레오파드 게코]
허물이 다 벗겨지지 않으면 발가락·꼬리 끝의 혈액 순환이 막혀 그 부위를 잃을 수 있다.
따뜻하게 적신 키친타월을 깐 통에 15~20분 넣어 불린 뒤 살살 떼어낸다. 안 떨어지면 다음 날 반복.
일주일이 지나도 안 떨어지면 특수동물 수의사 진료.
습식 은신처가 없는 것이 탈피 문제의 가장 흔한 원인.
```

## V0에서 박사가 지식을 쓰는 방식

- **해당 종의 활성 자료 전부를 프롬프트에 넣는다** (자료가 약 25개 주제라 충분)
- 박사는 답변과 함께 참고한 조각 ID를 돌려준다 → "참고 자료 보기" (05, 12)

> 확장 대비: 자료가 많아지면 주제로 거르기 → 의미 검색(RAG) 순서로 전환. 조각에 ID·주제·출처를 처음부터 붙여두는 이유

---

## 작업 순서

1. 즉시 병원 신호 목록 작성 → 숙련 사육자·가능하면 수의사 검토
2. 정답지에 쓰인 주제 작성 (굵게 표시된 것)
3. 정답지 13개 질문으로 박사 시험 (12 평가) → 부족한 주제 보완
4. 나머지 주제
