# 18. 즉시 병원 신호 목록

> 상태: **초안** — 숙련 사육자 검토, 가능하면 파충류 진료 수의사 검토 필요
> 할 일: T007 (W01)
> 쓰이는 곳: 04 기록 시점 검사 규칙, `red-flags` 사전 설계 흐름(16장 16.5), 13 정답지 #8, 14 지식 자료 "즉시 병원 신호 목록"

---

## 원칙

1. **애매하면 병원 쪽으로.** 파충류는 아픈 티를 숨기는 동물이라, 겉으로 보일 때는 이미 진행된 경우가 많다
2. **병명은 말하지 않는다.** 이 목록은 박사가 "무엇을 보고 병원을 권하는지"의 기준일 뿐, 집사에게 병명을 알려주지 않는다 (12 박사 원칙)
3. **판정은 코드가 한다.** 이 목록의 🔴 신호는 LLM 없이 규칙과 사전 설계 흐름으로 판정하고, 박사 하루 예산과 무관하게 항상 동작한다
4. **병원 안내에는 항상 "파충류 진료 가능 여부를 먼저 전화로 확인"을 붙인다.** 일반 동물병원은 파충류 진료 경험이 적을 수 있다
5. **신호가 겹치면 한 단계 올린다.** 🟠 신호가 두 개 이상 함께 있으면 🔴로 본다

---

## 🔴 즉시 병원 (오늘 연락)

박사 반응: 단호하게, 집에서 할 처치 대신 병원 연락. 진료용 기록 요약·지도 바로가기 제시 (06)

| #   | 집사가 보는 모습                                                           | 앱에서                                                      | 근거                                                                                  |
| --- | -------------------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| R1  | 항문(총배설강) 쪽으로 분홍·붉은 조직이 튀어나와 있음                       | 위험 신호 흐름                                              | 탈출(prolapse)은 즉시 진료가 필요한 응급 [1][2]                                       |
| R2  | 입 주변이 붓거나, 고름·하얀 덩어리가 보이거나, 입을 제대로 못 다묾         | 위험 신호 흐름, 정답지 #8                                   | 입 감염은 통증으로 먹지 못하게 되고 빠르게 악화 [1], 뼈 문제 진행 시 입을 못 다묾 [3] |
| R3  | 입을 벌리고 숨쉬거나, 숨소리가 쌕쌕거림                                    | 위험 신호 흐름                                              | 호흡기 문제 신호 [4][5]                                                               |
| R4  | 몸을 바닥에서 들어 올리지 못하거나, 다리가 휘어 보이거나, 턱이 말랑함      | 위험 신호 흐름                                              | 칼슘·D3 부족으로 인한 뼈 문제의 증상 [6][4]                                           |
| R5  | 떨림·경련, 등을 비정상적으로 굽히거나 몸을 비트는 움직임                   | 위험 신호 흐름                                              | 뼈 문제 진행 시 떨림 [1], 비정상 움직임은 중요한 경고 [7]                             |
| R6  | 만져도 거의 반응이 없을 정도로 축 처짐                                     | 위험 신호 흐름 첫 질문 (`body_condition: abnormal`)         | 무기력은 대표 경고 신호 [8]                                                           |
| R7  | 다리나 턱이 부어 있음                                                      | 위험 신호 흐름                                              | 수의사 케어시트의 경고 신호 [8]                                                       |
| R8  | 발가락·꼬리 끝이 거뭇하거나 부어 있음                                      | 발가락 확인 흐름 `toe-check` (`toe_color: dark_or_swollen`) | 남은 허물이 혈액 순환을 막아 그 부위를 잃을 수 있음 [9][10], 정답지 #4                |
| R9  | 뼈나 몸속이 보일 정도로 깊은 상처                                          | 위험 신호 흐름                                              | 깊은 상처는 수의사 처치 필요 [10]                                                     |
| R10 | (암컷) 배가 부풀고 힘을 주는데 알이 나오지 않음, 힘주다 항문 쪽이 튀어나옴 | 위험 신호 흐름                                              | 알막힘, 힘주다 탈출 동반 가능 [1][2]                                                  |
| R11 | 배설물에 피가 섞임                                                         | 기록 시점 검사 3단계 (`abnormal: blood`)                    | **앱 안전 원칙으로 보수적 설정** (04) — 검토 필요                                     |

## 🟠 1~2일 안에 병원 상담 (지속되거나 다른 신호와 겹치면)

박사 반응: 확인 질문 → 기록하며 지켜보되, 기준을 넘으면 병원 권고. 다른 🟠와 겹치면 🔴

| #   | 집사가 보는 모습                                           | 앱에서                                             | 근거                                                                                    |
| --- | ---------------------------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------- |
| O1  | 꼬리가 눈에 띄게 얇아짐, 체중이 짧은 기간에 빠짐           | 체중 감소 규칙, 기준 사진 비교, 정답지 #5          | 꼬리가 막대처럼 가늘어지는 것은 체중 감소 신호 [2], 급격한 체중 감소는 질병 가능성 [11] |
| O2  | 밥을 계속 안 먹음 (입양 초기·겨울철 제외 기준) + 체중 감소 | 급여 거부 규칙                                     | 식욕 저하는 대표 경고 신호 [8]                                                          |
| O3  | 묽은 변이 반복되거나, 냄새가 심함                          | 기록 시점 검사 2단계, 배변 확인 흐름 `stool-check` | 설사·체중 감소·거식이 함께 오면 분변 검사 필요 [1]                                      |
| O4  | 눈이 움푹 꺼짐, 피부가 쭈글쭈글, 입안이 끈적함             | 관찰 질문                                          | 탈수 신호 [11], 꺼진 눈은 심각한 상태의 첫 징후일 수 있음 [7]                           |
| O5  | 배가 부풀고 식욕·활동이 줄어듦                             | 관찰 질문                                          | 장 막힘 의심 신호 [2]                                                                   |
| O6  | 토하는 일이 반복됨                                         | 관찰 질문                                          | 한두 번 후 회복하면 괜찮지만 반복되면 진료 [12]                                         |
| O7  | 눈이 부었거나 계속 감고 있음                               | 관찰 질문                                          | 눈 문제는 흔한 질환 [13]                                                                |

박사 반응: 가볍게 안심 + 할 일 + 다시 찾아올 기준. 기록 시점 검사가 패턴을 본다

| G2  | 묽은 변 1회, 다른 이상 없음             | 기록 시점 검사 1단계, 정답지 #2    | 04 규칙                                                |

| G4  | 겨울철 식욕 감소, 체중 유지             | 계절 조정 규칙 (Should), 정답지 #7 | 04 규칙                                                |
| G5  | 낮에 은신처에 숨어 있음, 다른 이상 없음 | 없음 (정상 행동)                   | 펫테일은 야행성                                        |

## 사전 설계 흐름 `red-flags`에 들어갈 질문 (초안)

위험 신호 흐름은 **질문 3~4개 안에** 🔴 여부를 가려야 한다. 집사가 쉽게 답할 수 있는 순서로.

1. **몸 상태**: 축 처져 있거나, 몸을 못 들어 올리거나, 떨림이 있어? → R4·R5·R6
2. **숨**: 입을 벌리고 숨쉬거나 숨소리가 이상해? → R3
3. **눈에 보이는 곳**: 입 주변·항문 쪽·다리·발가락에 붓기, 튀어나온 것, 거뭇한 곳이 있어? → R1·R2·R7·R8·R10
4. 하나라도 "응" → 병원 권고 화면 (S09). 모두 "아니" → 원래 상담으로 돌아감

각 질문의 "잘 모르겠어"는 **사진 요청** 또는 한 단계 더 쉬운 하위 질문으로 이어진다 (03).
