# 17. 주차별 할 일

> 기준: 주 18시간, 15 개발 계획의 마일스톤(M1~M7)을 주 단위로 나눔 → **약 14주**
> 이 문서의 표가 GitHub 이슈의 원본이다. `pnpm issues:sync`가 이 표를 읽어 이슈를 **만들고, 고치고, 닫는다**
> 주차는 목표치다. 마일스톤의 완료 기준(15)을 채우는 것이 우선이고, M2가 끝날 때 속도를 보고 조정한다

---

## 표 읽는 법

| 열       | 값                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| ID       | `T001` ~. **할 일의 고유 번호. 한 번 정하면 바꾸지 않는다**                                                      |
| 주       | `W01` ~ `W14`                                                                                                    |
| 마일스톤 | `M1` ~ `M7` (15 개발 계획)                                                                                       |
| 저장소   | `app` = wizard-app · `backend` = wizard-backend · `planning` = wizard-app-planning                               |
| 유형     | `Feat` 기능 · `Settings` 설정 · `Content` 콘텐츠 · `Docs` 문서 · `Test` 테스트 · `Decision` 결정 · `Deploy` 배포 |
| 브랜치   | 작업 브랜치 이름. 코드가 없는 일은 `-`                                                                           |

- 두 저장소에 걸친 일은 저장소별로 나눠 적었다. 같은 브랜치 이름을 쓰고 **backend → app** 순서로 합친다
- 표의 열 순서와 구분자(`|`)를 바꾸면 스크립트가 읽지 못한다

### 계획을 바꿀 때

| 하고 싶은 것                 | 표에서                                  | 동기화하면                                        |
| ---------------------------- | --------------------------------------- | ------------------------------------------------- |
| 할 일 추가                   | 새 줄 추가, **새 ID** (마지막 번호 + 1) | 이슈 생성, 보드에 추가                            |
| 주차·마일스톤·시간·이름 변경 | 그 줄만 수정, **ID는 그대로**           | 이슈의 제목·라벨·마일스톤·본문 수정               |
| 할 일 빼기                   | 그 줄 삭제                              | 이슈를 "계획에서 제외됨"으로 닫음 (삭제하지 않음) |
| 다른 저장소로 옮기기         | 저장소 열 수정                          | 기존 이슈를 닫고 새 저장소에 생성                 |

- **이슈의 제목·라벨·마일스톤은 GitHub에서 직접 고치지 않는다.** 다음 동기화 때 표 기준으로 되돌아간다
- 이슈 본문의 자동 작성 영역 밖에 적은 메모와 댓글은 유지된다
- 완료되어 닫힌 이슈는 다시 열지 않는다

## GitHub Projects 사용법

1. GitHub에서 **Project** 하나 생성 (Board 보기)
2. 칸: `Backlog` → `이번 주` → `진행 중` → `리뷰` → `완료`
3. `PROJECT_NUMBER=<번호> pnpm issues:sync` → 세 저장소에 마일스톤, 라벨, 이슈 생성·수정 + 프로젝트에 추가
